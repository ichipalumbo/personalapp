# Personal Josy — kit final B

Este é o kit atualizado: amarelo #FFDE17, escuro #202020, J preenchido opaco e opção B para fundos claros. As entregas anteriores são históricas.

## O que está incluído
- Sete composições: horizontal, escrita, símbolo, empilhada, horizontal com descritor, empilhada com descritor e avatar.
- Cada uma tem aplicação clara e escura, com fundo transparente ou incorporado.
- SVG vetorial e PNG sRGB: 28 SVGs e 32 PNGs de marca.
- Avatar em 1080 × 1080 e 512 × 512 px; demais PNGs com 2400 px no lado maior.
- Prancha geral, referências horizontais, simulação de header, guia Markdown/PDF, manifesto JSON e verificação dos arquivos.

## Escolha do arquivo

| Aplicação | Transparente | Com fundo |
| --- | --- | --- |
| Clara B | Para suporte branco/claro; J opaco | Base branca #FFFFFF incorporada |
| Escura | Para suporte escuro; J opaco | Base #202020 incorporada |

Claro/escuro descreve a aplicação da marca, não só o retângulo de fundo. A versão clara tem Personal/presilhas/descritivo escuros e Josy amarelo com contorno B. A escura tem Personal/presilhas brancos, descritor #E0E0E0 e Josy sem contorno. O J é sempre #202020 opaco.

No header escuro, usar horizontal escura transparente sem descritor. No perfil, preferir o avatar com base incorporada; conferir o recorte na plataforma. Para apresentar o app, usar descritor apenas se houver leitura confortável.

A fonte do nome e do descritor já está convertida em curvas: não instalar fontes nem redigitar a marca. Não usar logo extraído de prancha. Não ampliar PNG pequeno como substituto de exportar o vetor.

A margem técnica de 12 unidades nos três mestres compactos evita corte do contorno e não substitui área de proteção. Desenho e espaçamentos foram preservados; só cores, J, aplicação clara B e enquadramento técnico foram atualizados.

Os arquivos são digitais sRGB. Não há versão monocromática, CMYK, favicon ou ícone de instalação homologado. Aplicativo e repositório não foram alterados. A simulação de header preserva o fundo original da interface.
